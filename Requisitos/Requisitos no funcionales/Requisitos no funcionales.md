## **Requisitos no funcionales**

# RNF01 - Usabilidad

El sistema deberá de contar con una interfaz simple, clara e intuitiva; permiendo a los usuarios y administradores una interacción libre y sin necesidad de capacitación previa.


# RNF02 - Compatibilidad

El sitio web debe poder ser accedido y visualizado correctamente desde los principales navegadores web:
* Google Chrome
* Mozilla Firefox
* Apple Safari
* Microsoft Edge
* Opera
* Brave

Asimismo, debe contar con un diseño responsivo que garantice su correcto funcionamiento y adaptabilidad en dispositivos móviles, tabletas y computadoras de escritorio.

# RNF03 - Mantenibilidad

El diseño de la plataforma debe permitir modificar, publicar y actualizar de manera efectiva y eficiente el directorio del DOCE, las entidades externas afines, los horarios, talleres, actividades y los avisos específicos o de generalidad del sitio. Todo esto sin la necesidad de modificar el código fuente directamente.

# RNF04 - Seguridad

Mediante un sistema de control de acceso y autenticación de cuentas, los administradores podrán iniciar sesión de forma segura en la página para crear, editar y publicar contenido relativo al DOCE.

# RNF05 - Rendimiento

El tiempo de carga del dominio web debe ser menor o igual a 3 segundos en condiciones habituales de conexión móvil 4G, con una velocidad mínima de 15 Mb/s.
