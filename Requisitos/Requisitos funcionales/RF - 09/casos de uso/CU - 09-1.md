## Requisito

RF09 - El sistema deberá permitir al administrador gestionar (subir, actualizar y eliminar) imágenes y descripciones en la fotogalería de las actividades de salud mental de la Facultad de Matemáticas, así como permitir a los usuarios visualizar dicha galería de forma pública.

### Objetivo

Permitir al administrador gestionar las fotografías de las actividades de salud mental mediante el registro, actualización y eliminación de imágenes con sus respectivos títulos y descripciones.

### Flujo principal

| Acción Actor | Acción Sistema |
|---|---|
| 1. El administrador accede al módulo de fotogalería. | 1. El sistema muestra las opciones para gestionar las fotografías registradas. |
| 2. El administrador selecciona la operación que desea realizar. | 2. El sistema presenta las opciones correspondientes a la operación seleccionada (agregar foto, actualizar foto o eliminar foto) |
| 3. El administrador selecciona agregar fotografía, elige una o varias imágenes e ingresa sus respectivos títulos y descripciones | 3. El sistema muestra la información proporcionada y solicita la confirmación del registro. |
| 4. El administrador selecciona actualizar fotografía y elige la imagen que desea modificar. | 4.  El sistema muestra la fotografía seleccionada, su título y descripción actuales para que el administrador pueda modificarlos. |
| 5. El administrador selecciona eliminar fotografía y elige la imagen que desea eliminar. | 5. El sistema muestra la fotografía seleccionada y solicita la confirmación de su eliminación. |
| 6. El administrador confirma la operación seleccionada. | 6. El sistema ejecuta la operación correspondiente (registra las fotografías con sus títulos y descripciones, guarda los cambios realizados o elimina permanentemente la fotografía y su información asociada) y muestra un mensaje con el resultado.|

### Flujos alternativos

| Flujo | Acción Actor | Acción Sistema |
|---|---|---|
| **Flujo Alternativo 1:** | El administrador intenta actualizar o eliminar una fotografía sin haber seleccionado alguna. | 1)  El sistema impide continuar con la operación.<br>2) Muestra el mensaje: "Se solicita que seleccione al menos una foto". |
| **Flujo Alternativo 2:** |  El administrador cancela la operación antes de confirmarla. | 1) El sistema cancela la operación sin aplicar los cambios. |
| **Flujo Alternativo 3:** | El administrador intenta actualizar o eliminar una fotografía que ya no está disponible. | 1) El sistema informa que la fotografía no está disponible.<br>2)  Actualiza el listado de fotografías. |

### Cierre

| Campo | Descripción |
|---|---|
| **Poscondición** | La fotografía queda registrada, actualizada o eliminada permanentemente, según la operación realizada. |
| **Frecuencia** | Cada vez que el administrador necesite administrar la fotogalería.|
| **Importancia** |  Permite mantener actualizada la fotogalería de las actividades relacionadas con la salud mental. |
