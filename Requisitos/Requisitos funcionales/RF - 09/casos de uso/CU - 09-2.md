## Requisito

RF09 - El sistema deberá permitir al administrador gestionar (subir, actualizar y eliminar) imágenes y descripciones en la fotogalería de las actividades de salud mental de la Facultad de Matemáticas, así como permitir a los usuarios visualizar dicha galería de forma pública.

## Caso de uso

| Campo | Descripción |
|---|---|
| **Nombre del Caso de Uso** | Fotogalería |
| **Código del Caso de Uso** | CU-09 |
| **Actor** | Usuario |
| **Precondición** | El usuario puede acceder a la página principal del sistema. No necesita iniciar sesión para consultar la fotogalería. |

### Objetivo

Permitir al usuario consultar las fotografías de las actividades de salud mental publicadas en la plataforma, para conocer visualmente las actividades e iniciativas realizadas.

### Flujo principal

| Acción Actor | Acción Sistema |
|---|---|
| 1. El usuario accede a la página de inicio del sistema. | 1. El sistema muestra la página principal. |
| 2. El usuario selecciona la sección "Fotogalería". | 2. El sistema muestra las fotografías publicadas junto con sus respectivos títulos y descripciones. |
| 3. El usuario recorre la fotogalería para consultar las fotografías disponibles. | 3. El sistema adapta la distribución de las fotografías al tamaño de la pantalla y permite consultar las imágenes mediante el desplazamiento de la página. |

### Flujos alternativos

| Flujo | Acción Actor | Acción Sistema |
|---|---|---|
| **Flujo Alternativo 1:** | El usuario accede a la sección de fotogalería y no hay fotografías disponibles. | El sistema muestra el mensaje: "No hay imágenes disponibles para consultar". |
| **Flujo Alternativo 2:** | El usuario accede a la sección de fotogalería, pero ocurre un error que impide cargar las imágenes. | El sistema muestra un mensaje indicando que no fue posible cargar las imágenes. |

### Cierre

| Campo | Descripción |
|---|---|
| **Poscondición** | El usuario consulta las fotografías disponibles o recibe un mensaje cuando no es posible mostrarlas. |
| **Frecuencia** | Cada vez que un usuario desee consultar la fotogalería.|
| **Importancia** |  Permite dar a conocer visualmente las actividades e iniciativas relacionadas con la salud mental. |
