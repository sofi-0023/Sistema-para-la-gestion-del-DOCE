## Requisito

RF09 - El sistema deberá permitir al administrador gestionar (subir, actualizar y retirar) imágenes y descripciones en la fotogalería de las actividades de salud mental de la Facultad de Matemáticas, así como permitir a los usuarios visualizar dicha galería de forma pública.

| **Precondición** |1) El administrador ha iniciado sesión y cuenta con permisos para administrar la fotogalería.<br>2) El usuario debe haber entrado correctamente a la página de inicio del sistema, posteriormente debió entrar a la pestaña llamada "Fotogalería" |

### Objetivo

Garantizar la publicación y difusión pública de las actividades de salud mental realizadas en la Facultad de Matemáticas, mediante una herramienta de gestión de contenido que permita al administrador mantener la fotogalería actualizada con imágenes y descripciones relevantes.

### Flujo principal

| Acción Actor | Acción Sistema |
|---|---|
| 1. El administrador accede al módulo de administracion de la "fotogalería". | 1. El sistema muestra las opciones para administrar la fotogalería |
| 2. El administrador selecciono la operación que desea realizar. | 2. El sistema Presenta las opciones correspondientes a la operación seleccionada (agregar foto, actualizar foto o retirar foto) |
| 3. El administrador selecciono agregar  foto | 3. El sistema selecciona la cantidad de fotos que todavía no está registrado en la plataforma, para su posterior implementacion. |
| 4. El administrador agrega una descripción en la fotografía | 4. El sistema dara la opcion de implementar un titulo y una breve descripción sobre la actividad. |
| 5. El administrador Selecciono atualizar fotografia. | 5. El sistema cambiara la fotografía(s) o la descripción de la fotografia. |
| 6. El administrador selecciono retirar foto | 6. El sistema eliminara de manera permanente la fotografia selecciona y con sus detalles. |
| 7. El administrador Confirma operación | 7. El sistema ejecuta la operación seleccionada y muestra un mensaje con el resultado |
| 8. El usuario selecciona la sección de la fotogalería. | 8. El sistema muestra las imágenes publicadas correspondientes a las actividades de salud mental realizadas en la Facultad de Matemáticas y se muestran las imagenes en manera de rectangulos o cuadrados. |
| 9. El usuario recorre la galería para consultar otras imágenes. | 9. El sistema permite visualizar las imágenes siguientes conforme el usuario se desplaza por la galería de manera Horizontal. |

### Flujos alternativos

| Flujo | Acción Actor | Acción Sistema |
|---|---|---|
| **Flujo Alternativo 1:** | No selecciona ninguna fotografia y confirma la operación. | 1) El sistema indica que no ha seleccionado la fotografia<br>2) Debajo de la fotogalería aparecerá el mensaje "se solicita que seleccione almenos una foto." |
| **Flujo Alternativo 2:** | Cancela la operación antes de confirmarla | 1)EL sistema cancela la operación sin aplicar los cambios. |
| **Flujo Alternativo 3:** | El usuario intenta actualizar o retirar la foto(s) que ya no está disponible. | 1) El  sistema informa que la fotografía(s) no está disponible y actualiza la fotogalería. |
| **Flujo Alternativo 4:** | El usuario accede a la sección de la fotogalería y no aparece la imagen. 1) El sistema muestra un mensaje indicando que "no hay imágenes disponibles para consultar". |
| **Flujo Alternativo 5:** | El usuario accede a la sección de la fotogalería no sé pudo mostrar la imagen o error al cargar la imagen | 1) El sistema Informa que no fue posible mostrar las imágenes. |

### Cierre

| Campo | Descripción |
|---|---|
| **Poscondición** | 1) La fotografía(s) queda agregado, actualizado o retirado, según la operación realizada.<br>2) El usuario consulta las imágenes disponibles o recibe información cuando no es posible mostrarlas. |
| **Frecuencia** | Cada vez que el administrador necesite administrar la fotogaleria. |
| **Importancia** | Una manera de demostrar que se cumplen las actividades relacionadas con la salud mental. |
