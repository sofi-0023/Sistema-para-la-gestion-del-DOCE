## Requisito

RF09 - El sistema deberá permitir al administrador gestionar (subir, actualizar y eliminar) imágenes y descripciones en la fotogalería de las actividades de salud mental de la Facultad de Matemáticas, así como permitir a los usuarios visualizar dicha galería de forma pública.

| **Precondición** |1) El administrador ha iniciado sesión y cuenta con permisos para administrar la fotogalería.<br>2) El usuario debe haber entrado correctamente a la página de inicio del sistema, posteriormente debió entrar a la pestaña llamada "Fotogalería" |

### Objetivo

Garantizar la publicación y difusión pública de las actividades de salud mental realizadas en la Facultad de Matemáticas, mediante una herramienta de gestión de contenido que permita al administrador mantener la fotogalería actualizada con imágenes y descripciones relevantes.

### Flujo principal

| Acción Actor | Acción Sistema |
|---|---|
| 1. El administrador accede al módulo de administración de la "fotogalería". | 1. El sistema muestra las opciones para administrar la fotogalería |
| 2. El administrador selecciona la operación que desea realizar. | 2. El sistema presenta las opciones correspondientes a la operación seleccionada (agregar foto, actualizar foto o eliminar foto) |
| 3. El administrador selecciona agregar foto | 3. El sistema selecciona la cantidad de fotos que todavía no están registradas en la plataforma, para su posterior implementación. |
| 4. El administrador agrega una descripción en la fotografía | 4. El sistema dará la opción de implementar un título y una breve descripción sobre la actividad. |
| 5. El administrador selecciona actualizar fotografía. | 5. El sistema cambia la(s) fotografía(s) o la descripción de la fotografía |
| 6. El administrador selecciona eliminar foto | 6. El sistema elimina de manera permanente la fotografía seleccionada junto con sus detalles.|
| 7. El administrador confirma operación | 7. El sistema ejecuta la operación seleccionada y muestra un mensaje con el resultado. |
| 8. El usuario selecciona la sección de la fotogalería. | 8. El sistema muestra las imágenes publicadas correspondientes a las actividades de salud mental realizadas en la Facultad de Matemáticas y se muestran las imágenes en forma de rectángulos o cuadrados. |
| 9. El usuario recorre la galería para consultar otras imágenes. | 9. El sistema permite visualizar las imágenes siguientes conforme el usuario se desplaza por la galería de manera horizontal. |

### Flujos alternativos

| Flujo | Acción Actor | Acción Sistema |
|---|---|---|
| **Flujo Alternativo 1:** | No selecciona ninguna fotografía y confirma la operación. | 1) El sistema indica que no ha seleccionado la fotografía<br>2) Debajo de la fotogalería aparecerá el mensaje "se solicita que seleccione al menos una foto." |
| **Flujo Alternativo 2:** | Cancela la operación antes de confirmarla | 1) El sistema cancela la operación sin aplicar los cambios. |
| **Flujo Alternativo 3:** | El administrador intenta actualizar o retirar la(s) foto(s) que ya no está(n) disponible(s). | 1) El sistema informa que la(s) fotografía(s) no está(n) disponible(s) y actualiza la fotogalería. |
| **Flujo Alternativo 4:** | El usuario accede a la sección de la fotogalería y no aparece la imagen. | 1) El sistema muestra un mensaje indicando que "no hay imágenes disponibles para consultar".|
| **Flujo Alternativo 5:** | El usuario accede a la sección de la fotogalería no se pudo mostrar la imagen o error al cargar la imagen | 1) El sistema informa que no fue posible mostrar las imágenes. |

### Cierre

| Campo | Descripción |
|---|---|
| **Poscondición** | 1) 1) La(s) fotografía(s) queda(n) agregada(s), actualizada(s) o retirada(s), según la operación realizada.<br>2) El usuario consulta las imágenes disponibles o recibe información cuando no es posible mostrarlas. |
| **Frecuencia** | Cada vez que el administrador necesite administrar la fotogalería.|
| **Importancia** |  Permite demostrar de manera visual que se cumplen las actividades relacionadas con la salud mental. |
