## Requisito

RF02 – El sistema deberá permitir al usuario seleccionar una actividad publicada en el calendario para consultar su información detallada, incluyendo nombre, descripción, fecha y hora, modalidad, lugar o enlace de acceso según corresponda, e institución u organizador responsable.

## Caso de uso

| Campo | Descripción |
|---|---|
| **Nombre del Caso de Uso** | Consultar detalle de actividad |
| **Código del Caso de Uso** | CU-02 |
| **Actor(es)** | Estudiante o usuario del sistema |
| **Precondición** | El usuario tiene acceso al calendario y puede seleccionar una actividad para consultar su información. |

### Objetivo

Consultar la información detallada de una actividad del calendario para conocer sus características y decidir si asistir.

### Flujo principal

| Acción Actor | Acción Sistema |
|---|---|
| 1. Selecciona una actividad del calendario. | 1. Verifica que la actividad continúe publicada y recupera su información. |
| 2. Consulta el detalle de la actividad. | 2. Muestra el nombre, descripción, fecha, hora, modalidad, lugar o enlace e institución u organizador responsable. |
| 3. Cierra el detalle o selecciona la opción de regresar. | 3. Muestra nuevamente el calendario. |

### Flujos alternativos

| Flujo | Acción Actor | Acción Sistema |
|---|---|---|
| **FA1 – Actividad no disponible** | 1) Selecciona una actividad que dejó de estar publicada. | 2) Informa que la actividad ya no está disponible y ofrece regresar al calendario. |
| **FA2 – Error de consulta** | 1) Intenta consultar el detalle de una actividad. | 2) Si ocurre un error al recuperar la información, muestra un mensaje de error y ofrece las opciones «Reintentar» y «Volver al calendario». |
| **FA2 – Reintentar consulta** | 3) Selecciona «Reintentar». | 4) Vuelve a realizar la consulta. Si tiene éxito, muestra el detalle; de lo contrario, mantiene el mensaje de error. |
| **FA2 – Regresar al calendario** | 5) Selecciona «Volver al calendario». | 6) Muestra nuevamente el calendario. |

### Cierre

| Campo | Descripción |
|---|---|
| **Poscondición** | Si la consulta termina correctamente, el usuario visualiza la información detallada de la actividad. Si ocurre una excepción, el sistema muestra el mensaje correspondiente y permite realizar la acción disponible. |
| **Frecuencia** | Cada vez que el usuario consulta una actividad. |
| **Importancia** | Permite conocer la información necesaria para decidir la asistencia. |
| **Comentarios** | La actividad debe encontrarse publicada para que el usuario pueda consultar su información. |
