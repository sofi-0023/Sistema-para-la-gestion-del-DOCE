## Requisito

RF07 - El sistema mostrará a los usuarios, de manera concisa, diferentes tipos de materiales informativos sobre salud mental, como lo son folletos, videos y documentos, pudiendo también seleccionar y acceder a cualquiera de estas publicaciones para poder conocer a detalle más acerca de las publicaciones.

## Caso de uso

| Campo | Descripción |
|---|---|
| **Nombre del Caso de Uso** | Visualización del catálogo de materiales informativos |
| **Código del Caso de Uso** | CU-07_1 |
| **Actor(es)** | Usuario del sistema |
| **Precondición** | 1.- El sistema debe estar disponible.
2.- El usuario debe poder acceder al sistema.
3.- El usuario puede acceder a la sección de materiales informativos.
4.- El sistema tiene almacenado materiales informativos.
5.- Existe un mecanismo para consultar las publicaciones registradas.
6.- Existen publicaciones para visualizar. |

### Objetivo

Permitir que los usuarios visualicen un catálogo de materiales informativos sobre salud mental, presentado de manera concisa y organizada.

### Flujo principal

| Acción Actor | Acción Sistema |
|---|---|
| 1. El usuario accede al sistema. | 1. El sistema muestra la opción para ver los materiales informativos. |
| 2. El usuario selecciona la opción "Materiales Informativos". | 2. El sistema recibe la solicitud de visualización del catálogo y redirecciona al usuario para verlas. |
| 2.1  | 2.1 El sistema consulta el repositorio de publicaciones disponibles para los usuarios. |
| 2.2  | 2.2 El sistema devuelve las publicaciones disponibles para visualizar. |
| 2.3  | 2.3 El sistema organiza las publicaciones para su presentación en el catálogo. |
| 2.4  | 2.4 El sistema identifica el tipo de cada material: folleto, video o documento. |
| 2.5  | 2.5 El sistema presenta la información resumida de cada publicación, como título, descripción breve y tipo. |
| 3. El usuario revisa las publicaciones disponibles. | 3. El sistema permite su visualización y permanece en la sección. |
| 4. El usuario selecciona una publicación que le interesa consultar. | 4. El sistema sigue su curso y el caso de uso finaliza. |

### Flujos alternativos

| ID Flujo | Situación | Acción Sistema |
|---|---|---|
| **FA01** | No existen publicaciones disponibles. | El sistema muestra el catálogo vacío con un mensaje informando de la ausencia de materiales informativos. |
| **FA02** | Una publicación no cuenta con descripción. | El sistema indica que la publicación no cuenta con descripción. |
| **FA03** | Existen más publicaciones de las que caben en una página. | El sistema muestra las publicaciones por páginas o mediante desplazamiento, sin omitir registros. |
| **FA04** | La publicación fue retirada mientras el usuario consultaba el catálogo. | El sistema actualiza la lista o informa que la publicación ya no está disponible cuando el usuario intente seleccionarla. |
| **FA05** | Ocurre un error al recuperar la información registrada. | El sistema muestra un mensaje de error e indica que no fue posible cargar los materiales informativos. |
| **FA06** | Se pierde la conexión con el servidor. | El sistema muestra un mensaje de error con la conección de intermnet e indica que no fue posible cargar el sitio. |

### Cierre

| Campo | Descripción |
|---|---|
| **Poscondición** | 1. Exito: El sistema muestra el catálogo al usuario.
2. Sin Publicaciones o Error: El sistema informa que el catálogo no pudo cargarse o que no existen publicaciones disponibles. |
| **Frecuencia** | Siempre |
| **Importancia** | Permitir al usuario consultar de forma concisa los materiales sobre salud mental disponibles en el sistema. |
