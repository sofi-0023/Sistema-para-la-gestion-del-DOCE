## Requisito

RF07 - El sistema mostrará a los usuarios, de manera concisa, diferentes tipos de materiales informativos sobre salud mental, como lo son folletos, videos y documentos, pudiendo también seleccionar y acceder a cualquiera de estas publicaciones para poder conocer a detalle más acerca de las publicaciones.

## Caso de uso

| Campo | Descripción |
|---|---|
| **Nombre del Caso de Uso** | Consultar detalles de una publicación |
| **Código del Caso de Uso** | CU-07_2 |
| **Actor(es)** | Usuario del sistema |
| **Precondición** | 1.- El sistema debe estar disponible.<br>2.- El usuario debe poder acceder al sistema.<br>3.- El usuario puede acceder a la sección de materiales informativos.<br>4.- El sistema tiene almacenado materiales informativos.<br>5.- Existe un mecanismo para consultar las publicaciones registradas.<br>6.- Existen publicaciones para visualizar.<br>7.- Las publicaciones están habilitadas para su consulta. |

### Objetivo

Permitir que los usuarios consulten la información detallada de cada material informativo en el catálogo de la página.

### Flujo principal

| Acción Actor | Acción Sistema |
|---|---|
| 1. El usuario accede al sistema. | 1. El sistema muestra la opción para ver los materiales informativos. |
| 2. El usuario selecciona la opción "Materiales Informativos". | 2. El sistema recibe la solicitud de visualización del catálogo conforme al CU-07_1. |
| 3. El usuario revisa las publicaciones y selecciona una que le interesa. | 3. El sistema identifica la publicación seleccionada. |
| 3.1  | 3.1 El sistema devuelve la información almacenada para el registro solicitado. |
| 3.2  | 3.2 El sistema organiza los datos recuperados para su presentación. |
| 3.3  | 3.3 El sistema muestra el título, la descripción detallada, el tipo de material y los demás datos disponibles. |
| 4. El usuario lee la información detallada de la publicación. | 4. El sistema mantiene visible el material informativo mientras el usuario permanece en esta sección. |
| 5. El usuario decide acceder al material de referencia o desea regresar al catálogo. | 5. El sistema sigue su curso y el caso de uso finaliza. |

### Flujos alternativos

| ID Flujo | Situación | Acción Sistema |
|---|---|---|
| **FA01** | El usuario decide regresar al catálogo. | El sistema vuelve a CU-07_1 y muestra las publicaciones disponibles. |
| **FA02** | La publicación es un video. | El sistema muestra su duración, descripción y plataforma de reproducción, en caso de no estar almacenado en el sitio. |
| **FA03** | La publicación es un documento. | El sistema muestra una vista previa del archivo, su formato, el tamaño, el archivo para descargar y/o la forma de acceder a su contenido. |
| **FA04** | La publicación es un folleto. | El sistema muestra una vista previa del archivo, una descripción del folleto, el archivo para descargar y/o la forma de acceder a su contenido. |
| **FA05** | La publicación fue retirada mientras el usuario consultaba el catálogo. | El sistema informa que el material ya no está disponible y ofrece regresar al catálogo actualizado. |
| **FA06** | No se encuentra la publicación solicitada. | El sistema informa del error y permanece en la sección del catálogo. |
| **FA07** | Se pierde la conexión con el servidor. | El sistema muestra un mensaje de error con la conexión a internet e indica que no fue posible cargar el sitio. |
| **FA08** | El enlace a un recurso externo no está disponible. | El sistema informa que el contenido no está disponible. |

### Cierre

| Campo | Descripción |
|---|---|
| **Poscondición** | 1. Éxito: El sistema muestra los detalles de la publicación seleccionada.<br>2. Error: El sistema informa que no fue posible consultar los detalles y/o el enlace externo. |
| **Frecuencia** | Siempre |
| **Importancia** | Consultar material de referencia de interés para los usuarios. |
