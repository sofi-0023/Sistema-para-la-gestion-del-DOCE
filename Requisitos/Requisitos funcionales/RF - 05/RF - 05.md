## Caso de uso

| Campo                  | Descripción                                                                 |
| ---------------------- | --------------------------------------------------------------------------- |
| Nombre del Caso de Uso | Consultar directorio de orientación y psicología                            |
| Código del Caso de Uso | CU-05                                                                       |
| Actor(es)              | Estudiante (Usuario)                                                        |
| Precondición           | El usuario ha accedido a la plataforma                                      |

## Flujo principal

| Acción Actor                                      | Acción Sistema                                                                 |
| ------------------------------------------------- | ------------------------------------------------------------------------------ |
| 1. Selecciona la sección “Directorio” o “Contactos” | 1. Muestra el listado de orientadores y psicólogos                            |
| 2. Visualiza la información de cada persona       | 2. Presenta para cada persona: nombre completo, cargo/área, ubicación física, horario de atención y correo/teléfono |
| 3. (Opcional) Selecciona un contacto para ver más detalle | 3. Muestra la ficha completa del profesional seleccionado                  |

## Flujos alternativos

| Flujo                     | Acción Actor                          | Acción Sistema                                      |
| ------------------------- | ------------------------------------- | --------------------------------------------------- |
| Flujo Alternativo 1       | 1) No hay contactos registrados       | 2) Muestra mensaje “No hay contactos disponibles por el momento” |
| Flujo Alternativo 2       | 1) Intenta acceder sin conexión       | 2) Muestra mensaje de error de conexión             |

## Cierre

| Campo        | Descripción                                                                 |
| ------------ | --------------------------------------------------------------------------- |
| Poscondición | El usuario ha consultado la información de contacto y horarios del DOCE     |
| Frecuencia   | Alta (consulta frecuente por parte del estudiantado)                        |
| Importancia  | Alta (Must)                                                                 |
| Comentarios  | No requiere inicio de sesión. La información debe poder actualizarse desde el panel de administración |
