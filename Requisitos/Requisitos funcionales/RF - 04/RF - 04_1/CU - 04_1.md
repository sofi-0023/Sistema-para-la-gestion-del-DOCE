## Caso de uso

| Campo                  | Descripción                                                                 |
| ---------------------- | --------------------------------------------------------------------------- |
| Nombre del Caso de Uso | Editar actividad o aviso                                                    |
| Código del Caso de Uso | CU-04.1                                                                     |
| Actor(es)              | Administrador                                                               |
| Precondición           | El administrador ha iniciado sesión y existe al menos una actividad o aviso publicado |

## Flujo principal

| Acción Actor                                      | Acción Sistema                                                                 |
| ------------------------------------------------- | ------------------------------------------------------------------------------ |
| 1. Selecciona una actividad o aviso publicado     | 1. Muestra el formulario con los datos actuales de la actividad/aviso          |
| 2. Modifica uno o más campos (nombre, descripción, fecha, hora, modalidad, lugar/enlace, organizador) | 2. Valida que los campos obligatorios estén completos y con formato correcto |
| 3. Confirma los cambios                           | 3. Guarda los cambios y actualiza la actividad/aviso en el sistema             |
|                                                   | 4. Muestra mensaje de confirmación “Cambios guardados correctamente”           |
|                                                   | 5. Actualiza la vista del calendario/catálogo con la nueva información         |

## Flujos alternativos

| Flujo                     | Acción Actor                          | Acción Sistema                                      |
| ------------------------- | ------------------------------------- | --------------------------------------------------- |
| Flujo Alternativo 1       | 1) Cancela la edición                 | 2) Descarta los cambios y regresa a la vista anterior |
| Flujo Alternativo 2       | 1) Deja un campo obligatorio vacío    | 2) Muestra mensaje de error e impide guardar          |

## Cierre

| Campo        | Descripción                                                                 |
| ------------ | --------------------------------------------------------------------------- |
| Poscondición | La actividad o aviso queda actualizado con los nuevos datos y es visible para los usuarios |
| Frecuencia   | Media (cuando hay errores o cambios de último momento)                      |
| Importancia  | Alta (Must)                                                                 |
| Comentarios  | Solo el administrador autenticado puede realizar esta acción                |
