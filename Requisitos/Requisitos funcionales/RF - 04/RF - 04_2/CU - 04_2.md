## Caso de uso

| Campo                  | Descripción                                                                 |
| ---------------------- | --------------------------------------------------------------------------- |
| Nombre del Caso de Uso | Cancelar / retirar actividad o aviso                                        |
| Código del Caso de Uso | CU-04.2                                                                     |
| Actor(es)              | Administrador                                                               |
| Precondición           | El administrador ha iniciado sesión y existe al menos una actividad o aviso publicado |

## Flujo principal

| Acción Actor                                      | Acción Sistema                                                                 |
| ------------------------------------------------- | ------------------------------------------------------------------------------ |
| 1. Selecciona una actividad o aviso publicado     | 1. Muestra los detalles de la actividad/aviso                                  |
| 2. Elige la opción “Cancelar” o “Retirar”         | 2. Solicita confirmación de la acción                                          |
| 3. Confirma la cancelación                        | 3. Marca la actividad/aviso como “Cancelada”                                   |
|                                                   | 4. Mantiene la actividad visible en el calendario con la etiqueta “Cancelada”  |
|                                                   | 5. Muestra mensaje de confirmación “Actividad cancelada correctamente”         |

## Flujos alternativos

| Flujo                     | Acción Actor                          | Acción Sistema                                      |
| ------------------------- | ------------------------------------- | --------------------------------------------------- |
| Flujo Alternativo 1       | 1) Cancela la operación               | 2) No realiza ningún cambio y regresa a la vista anterior |
| Flujo Alternativo 2       | 1) Intenta cancelar una actividad ya cancelada | 2) Muestra mensaje “Esta actividad ya está cancelada” |

## Cierre

| Campo        | Descripción                                                                 |
| ------------ | --------------------------------------------------------------------------- |
| Poscondición | La actividad o aviso aparece marcada como “Cancelada” y sigue visible hasta su fecha original |
| Frecuencia   | Baja-Media (solo cuando hay cancelaciones)                                  |
| Importancia  | Alta (Must)                                                                 |
| Comentarios  | No se elimina del sistema, solo se marca como cancelada                     |
