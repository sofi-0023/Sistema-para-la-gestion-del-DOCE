## Requisito

RF03.2 – El sistema deberá permitir al administrador publicar una actividad previamente registrada como borrador para que los usuarios puedan consultarla en el calendario.

## Caso de uso

| Campo | Descripción |
|---|---|
| **Nombre del Caso de Uso** | Publicar actividad |
| **Código del Caso de Uso** | CU-04 |
| **Actor(es)** | Administrador del sistema |
| **Precondición** | El administrador ha iniciado sesión, cuenta con permisos de publicación y existe una actividad registrada en estado «Borrador». |

### Objetivo

Publicar una actividad previamente guardada como borrador para que la comunidad estudiantil pueda consultarla en el calendario.

### Flujo principal

| Acción Actor | Acción Sistema |
|---|---|
| 1. Selecciona una actividad en borrador desde la administración de actividades. | 1. Muestra la información completa de la actividad y la opción «Publicar». |
| 2. Revisa la información y selecciona «Publicar». | 2. Verifica que la actividad continúe en estado «Borrador» y que cumpla con los requisitos de información obligatoria. |
| | 3. Cambia el estado de la actividad a «Publicado». |
| | 4. Hace visible la actividad en el calendario para la comunidad estudiantil. |
| | 5. Confirma que la actividad se publicó correctamente. |

### Flujos alternativos

| Flujo | Acción Actor | Acción Sistema |
|---|---|---|
| **FA1 – Información incompleta o inválida** | 1) Intenta publicar una actividad que no cumple con los requisitos establecidos. | 2) Informa qué datos requieren corrección y mantiene la actividad en estado «Borrador». |
| **FA2 – Actividad ya publicada** | 1) Intenta publicar una actividad que ya fue publicada anteriormente. | 2) Informa que la actividad ya está publicada y evita duplicar la operación. |
| **FA3 – Error de publicación** | 1) Intenta publicar la actividad. | 2) Si ocurre un error que impide completar la publicación, informa que no se realizó ningún cambio y mantiene la actividad como «Borrador», sin mostrarla en el calendario público. |

### Cierre

| Campo | Descripción |
|---|---|
| **Poscondición** | La actividad queda en estado «Publicado» y visible en el calendario para la comunidad estudiantil. Si ocurre un error, permanece como «Borrador». |
| **Frecuencia** | Cada vez que una actividad está lista para difundirse. |
| **Importancia** | Permite que los usuarios conozcan las actividades y consulten sus detalles. |
| **Comentarios** | La publicación no implica enviar notificaciones. |
