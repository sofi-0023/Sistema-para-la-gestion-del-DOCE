## Requisito

RF03.3 – El sistema deberá permitir al administrador registrar un aviso como borrador mediante un formulario que solicite título y contenido.

## Caso de uso

| Campo | Descripción |
|---|---|
| **Nombre del Caso de Uso** | Crear aviso como borrador |
| **Código del Caso de Uso** | CU-05 |
| **Actor(es)** | Administrador del sistema |
| **Precondición** | El administrador ha iniciado sesión y cuenta con permisos para crear avisos. |

### Objetivo

Registrar el título y contenido de un aviso y guardarlo como borrador para preparar su publicación.

### Flujo principal

| Acción Actor | Acción Sistema |
|---|---|
| 1. Selecciona «Crear aviso». | 1. Muestra el formulario de registro. |
| 2. Captura el título y el contenido del aviso. | 2. Permite ingresar la información correspondiente. |
| 3. Selecciona «Guardar borrador». | 3. Valida que el título y el contenido no estén vacíos ni contengan únicamente espacios. |
| | 4. Si la información es válida, registra el aviso con estado «Borrador». |
| | 5. Confirma que el borrador se guardó correctamente. |

### Flujos alternativos

| Flujo | Acción Actor | Acción Sistema |
|---|---|---|
| **FA1 – Campos obligatorios vacíos o inválidos** | 1) Intenta guardar el aviso sin título o contenido válido. | 2) Señala los campos que necesitan corrección, conserva la información capturada y permite completar nuevamente el formulario. |
| **FA2 – Cancelación** | 1) Selecciona «Cancelar» antes de guardar. | 2) Finaliza el proceso sin registrar el aviso. |
| **FA3 – Error de almacenamiento** | 1) Intenta guardar el aviso. | 2) Si ocurre un error durante el almacenamiento, informa que no se pudo completar el registro, conserva los datos capturados y permite reintentar. |

### Cierre

| Campo | Descripción |
|---|---|
| **Poscondición** | El aviso queda registrado como «Borrador» y disponible para su consulta administrativa. |
| **Frecuencia** | Cada vez que el administrador necesita preparar un comunicado. |
| **Importancia** | Permite preparar información relevante para la comunidad estudiantil antes de publicarla. |
| **Comentarios** | El aviso requiere título y contenido. Guardarlo no lo hace visible para la comunidad. |
