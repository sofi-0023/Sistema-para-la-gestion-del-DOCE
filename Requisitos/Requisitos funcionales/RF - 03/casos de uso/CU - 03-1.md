## Requisito

RF03.1 – El sistema deberá permitir al administrador registrar una actividad como borrador mediante un formulario que solicite nombre, descripción, fecha y hora, modalidad, lugar o enlace de acceso según corresponda, e institución u organizador responsable.

## Caso de uso

| Campo | Descripción |
|---|---|
| **Nombre del Caso de Uso** | Crear actividad como borrador |
| **Código del Caso de Uso** | CU-03 |
| **Actor(es)** | Administrador del sistema |
| **Precondición** | El administrador ha iniciado sesión y cuenta con permisos para crear actividades. |

### Objetivo

Registrar los datos de una actividad y guardarla como borrador para preparar su publicación.

### Flujo principal

| Acción Actor | Acción Sistema |
|---|---|
| 1. Selecciona «Crear actividad». | 1. Muestra el formulario de registro. |
| 2. Captura el nombre, descripción, fecha y hora, modalidad, lugar o enlace e institución u organizador. | 2. Permite ingresar los datos y señala los campos obligatorios según la modalidad seleccionada. |
| 3. Selecciona «Guardar borrador». | 3. Valida los campos obligatorios, sus formatos y la coherencia de los datos. |
| | 4. Si la información es válida, registra la actividad con estado «Borrador». |
| | 5. Confirma que el borrador se guardó correctamente. |

### Flujos alternativos

| Flujo | Acción Actor | Acción Sistema |
|---|---|---|
| **FA1 – Datos incompletos o inválidos** | 1) Intenta guardar la actividad con datos faltantes o incorrectos. | 2) Señala los campos que necesitan corrección, conserva la información capturada y permite completar nuevamente el formulario. |
| **FA2 – Cancelación** | 1) Selecciona «Cancelar» antes de guardar. | 2) Finaliza el proceso sin registrar la actividad. |
| **FA3 – Error de almacenamiento** | 1) Intenta guardar la actividad. | 2) Si ocurre un error durante el almacenamiento, informa que no se pudo completar el registro, conserva los datos capturados y permite reintentar. |

### Cierre

| Campo | Descripción |
|---|---|
| **Poscondición** | La actividad queda registrada como «Borrador» y disponible para su consulta administrativa. |
| **Frecuencia** | Cada vez que el administrador necesita registrar una actividad. |
| **Importancia** | Permite preparar la información de las actividades antes de hacerlas visibles para la comunidad estudiantil. |
| **Comentarios** | Guardar el borrador no hace visible la actividad para los estudiantes. |
