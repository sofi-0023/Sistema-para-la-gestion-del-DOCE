## Requisito

RF08 - El sistema deberá permitir al administrador registrar nuevos materiales informativos, modificar los materiales registrados y eliminar de la consulta pública los materiales publicados.

### Objetivo

El administrador debe poder acceder a la gestión de recursos de salud mental y agregar, actualizar y retirar el material existente.

### Flujo principal

| Acción Actor | Acción Sistema |
|---|---|
| 1. El administrador accede al módulo de material informativo.| 1. El sistema muestra los materiales registrados y las opciones de gestión. |
| 2. El administrador selecciona la operación que desea realizar. | 2. El sistema presenta las opciones correspondientes: agregar material, actualizar material y eliminar material. |
| 3. El administrador selecciona agregar material | 3. El sistema muestra el formulario  para registrar un nuevo material informativo y solicita los datos correpondientes. |
| 4. El administrador selecciona actualizar material y elige  el material que desea modificar | 4. El sistema muestra la información del material seleccionado para que el administrador pueda modificar. |
| 5. El administrador selecciona eliminar material y elige el material que desea eliminar de la consulta pública. | 5. El sistema muestra el material seleccionado y solicita la confirmación de su eliminación. |
| 6. El administrador confirma la operación seleccionada | 6. El sistema ejecuta la operación correspondiente (registra el nuevo material, guarda los cambios realizaos o elimina el material de la consulta pública) y muestra un mensaje con el resultado. |

### Flujos alternativos

| Flujo | Acción Actor | Acción Sistema |
|---|---|---|
| **Flujo Alternativo 1:** | Intenta actualizar o eliminar sin seleccionar un material y confirma. | 1) Muestra << Se solicita que seleccione un material >> Debajo del apartado Gestión de recursos de salud mental. No realiza cambios. |
| **Flujo Alternativo 2:** | Cancela la operación antes de confirmarla. | 1) Cancela la operación sin aplicar los cambios. |
| **Flujo Alternativo 3:** | Intenta actualizar o eliminar un material que dejo de estar disponible. | 1) Informa que el material no está disponible y actualiza el listado. |
| **Flujo Alternativo 4:** | Una persona sin permisos intenta acceder al módulo | 1) Impide el acceso a la gestión de materiales. |

### Cierre

| Campo | Descripción |
|---|---|
| **Poscondición** | El material queda registrado, actualizado o retirado de la consulta pública, según la operación confirmada. Si la operación se cancela o no puede completarse, los datos permanecen sin cambios. |
| **Frecuencia** | Cada vez que el administrador necesite gestionar material informativo. |
| **Importancia** | Permite mantener actualizada la información sobre salud mental disponible en la plataforma y retirar materiales que ya no deban consultarse, evitando que los usuarios encuentren información desactualizada. |
