## Requisito

RF08 - El sistema deberá permitir al administrador registrar nuevos materiales informativos, modificar los materiales registrados y eliminar de la consulta pública los materiales publicados.

### Objetivo

El administrador debe poder acceder a la gestión de recursos de salud mental y agregar, actualizar y retirar el material existente.

### Flujo principal

| Acción Actor | Acción Sistema |
|---|---|
| 1. El administrador accede al módulo de material informativo.| 1. El sistema muestra las opciones para gestionar el material registrado. |
| 2. El administrador selecciona la operación que desea realizar. | 2. El sistema presenta las opciones correspondientes a la operación seleccionada (agregar material, actualizar material o eliminar material). |
| 3. El administrador selecciona agregar material | 3. El sistema muestra la selección del material de salud mental que todavía no está registrado en la plataforma, para su posterior implementación. |
| 4. El administrador selecciona actualizar material | 4. El sistema modifica un material que ya está registrado. |
| 5. El administrador selecciona eliminar material | 5. El sistema elimina el material seleccionado. |
| 6. El administrador confirma la operación | 6. El sistema ejecuta la operación seleccionada y muestra un mensaje con el resultado. |

### Flujos alternativos

| Flujo | Acción Actor | Acción Sistema |
|---|---|---|
| **Flujo Alternativo 1:** | No selecciona ningún material y confirma la operación. | 1) Indica que no ha seleccionado el material.<br>2) Debajo de la gestión de recursos de salud mental aparecerá el mensaje "se solicita que seleccione un material". |
| **Flujo Alternativo 2:** | Cancela la operación antes de confirmarla. | 1) Cancela la operación sin aplicar los cambios. |
| **Flujo Alternativo 3:** | Intenta actualizar o eliminar un material que ya no está disponible. | 1) Informa que el material no está disponible y actualiza el listado. |

### Cierre

| Campo | Descripción |
|---|---|
| **Poscondición** | El material queda agregado, actualizado o retirado, según la operación realizada.. |
| **Frecuencia** | Cada vez que el administrador necesite gestionar material informativo. |
| **Importancia** | Permite mantener actualizada la información sobre salud mental disponible en la plataforma y retirar materiales que ya no deban consultarse, evitando que los usuarios encuentren información desactualizada. |
