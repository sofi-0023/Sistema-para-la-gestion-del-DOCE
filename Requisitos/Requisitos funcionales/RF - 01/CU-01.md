## Requisito

RF01 - El sistema mostrará un calendario de las actividades ya publicadas, cuya fecha sea igual o posterior al día actual, indicando nombre, lugar, fecha y hora de cada una.

## Caso de uso

| Campo | Descripción |
|---|---|
| **Nombre del Caso de Uso** | Consultar calendario |
| **Código del Caso de Uso** | CU-01 |
| **Actor(es)** | Estudiante |
| **Precondición** | El usuario está en cualquier página pública del sistema. No necesita iniciar sesión. |

### Objetivo

El usuario consulta en el calendario las actividades publicadas a partir de hoy, con su nombre, fecha, hora y lugar.

### Flujo principal

| Acción Actor | Acción Sistema |
|---|---|
| 1. El usuario selecciona la pestaña "Calendario" | 2. El sistema muestra el mes actual con las actividades publicadas cuya fecha sea igual o posterior al día actual, cada una en su día con nombre, hora y lugar. Las canceladas llevan la etiqueta "Cancelada" |
| 3. El usuario cambia de mes o a la vista Lista | 4. El sistema muestra las actividades del periodo elegido con el mismo filtro |
| 5. El usuario selecciona una actividad | 6. El sistema muestra su detalle (extiende a CU-02) |

### Flujos alternativos

| Flujo | Condición | Acción Sistema |
|---|---|---|
| **Flujo Alternativo 1:** | No hay actividades publicadas a partir de hoy (paso 2) | 1) El calendario aparece vacío<br>2) Debajo del calendario se muestra el mensaje "No hay eventos por mostrar" |
| **Flujo Alternativo 2:** | No hay conexión con el servidor (paso 2) | 1) El usuario permanece en la pestaña "Calendario"<br>2) Se muestra el mensaje "No se pudo conectar con los servidores, intenta de nuevo más tarde" |
| **Flujo Alternativo 3:** | La actividad seleccionada dejó de estar publicada (paso 5) | 1) El sistema regresa al usuario al calendario<br>2) Se muestra el mensaje "La actividad ya no está disponible" |

### Cierre

| Campo | Descripción |
|---|---|
| **Poscondición** | El usuario consultó las actividades publicadas a partir de hoy, con su nombre, fecha, hora y lugar. |
| **Frecuencia** | Cada vez que un usuario consulta el calendario |
| **Importancia** | Proceso indispensable para la consulta de actividades propuestas por el DOCE |
