## Requisito Funcional - 14

RF14 - El sistema deberá permitir al administrador iniciar y cerrar sesión para acceder a las funciones de gestión de contenido.

## Caso de uso

| Campo | Descripción |
|---|---|
| **Nombre del Caso de Uso** | Inicio y cierre de sesión de administrador |
| **Código del Caso de Uso** | CU-14 |
| **Actor(es)** | Administrador del sistema |
| **Precondición** | Estar registrado con rol de administrador |

### Objetivo

Autenticar al administrador y permitir su salida segura del sistema.

### Flujo principal

| Acción Actor | Acción Sistema |
|---|---|
| 1. Ingresa usuario y contraseña. | 1. Valida las credenciales y otorga acceso al panel. |
| 2. Selecciona cerrar sesión al terminar. | 2. Invalida el token y redirige al inicio público. |

### Flujos alternativos

| Flujo | Acción Actor | Acción Sistema |
|---|---|---|
| **Flujo Alternativo 1:** | Ingresa credenciales incorrectas. | 1. El sistema valida los datos y detecta error.<br>2. Muestra el mensaje "Credenciales inválidas, intente de nuevo". |
| **Flujo Alternativo 2:** | El administrador quiere cancelar el inicio de sesión. | 1. Hace clic en cancelar.<br>2. El sistema limpia los campos y regresa a la pantalla principal. |

### Cierre

| Campo | Descripción |
|---|---|
| **Poscondición** | El administrador inició sesión de forma segura o cerró su sesión actual. |
| **Frecuencia** | Cada vez que se requiera gestionar contenido. |
| **Importancia** | Crítica para la seguridad y control de acceso al sistema. |
