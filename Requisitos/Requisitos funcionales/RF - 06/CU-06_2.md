## Requisito

RF06 - El sistema deberá permitir la gestión y visualización de las líneas de ayuda universitarias, así también las de disposición general locales, estatales y nacionales para los usuarios.

## Caso de uso

| Campo | Descripción |
|---|---|
| **Nombre del Caso de Uso** | Registrar líneas de ayuda |
| **Código del Caso de Uso** | CU-06_2 |
| **Actor(es)** | Administrador del sistema |
| **Precondición** | 1.- El sistema debe estar disponible.
2.- El administrador debe poder acceder al sistema.
3.- El administrador ha validado sus credenciales como "administrador".
4.- El administrador cuenta con los permisos necesarios para registrar líneas de ayuda.
5.- El formulario de registro de líneas de ayuda se encuentra disponible.
6.- El administrador dispone de la información que registrará en las líneas de ayuda. |

### Objetivo

Permitir que el administrador incorpore al sistema una nueva(s) línea(s) de ayuda, registrando sus datos de identificación, ámbito de atención, descripción del servicio y medios de contacto, de manera que la información quede almacenada en el sitio y pueda utilizarse en la gestión y visualización del catálogo.

### Flujo principal

| Acción Actor | Acción Sistema |
|---|---|
| 1. El administrador ingresa al sistema. | 1. El sistema presenta la pantalla principal o el panel administrativo, con sus respectivos permisos. |
| 2. El administrador accede al módulo de gestión de líneas de ayuda. | 2. El sistema presenta las opciones disponibles para administrar los registros de líneas de ayuda. |
| 3. El administrador selecciona la opción para registrar líneas de ayuda. | 3. El sistema inicia el proceso de registro de información y presenta el formulario correspondiente. |
| 4. El administrador consulta los campos del formulario. | 4. El sistema muestra los campos de identificación, clasificación, descripción y de contacto. |
| 5. El administrador introduce el nombre de la línea. | 5. El sistema recibe el dato proporcionado. |
| 6. El administrador selecciona el ámbito correspondiente a la línea de ayuda. | 6. El sistema registra la selección. |
| 7. El administrador introduce la información institucional y descriptiva de la línea de ayuda correspondiente. | 7. El sistema recibe los datos proporcionados. |
| 8. El administrador introduce los datos de contacto y horarios de atención. | 8. El sistema recibe los datos del formulario. |
| 9. El administrador completa los campos requeridos y solicita guardar el registro. | 9. El sistema recibe la solicitud de registro. |
| 9.1 | 9.1 El sistema verifica que los campos requeridos estén completos. |
| 9.2 | 9.2 El sistema valida los formatos de los datos capturados. |
| 9.3 | 9.3 El sistema comprueba si existe un registro con el que se considere duplicado. |
| 9.4 | 9.4 El sistema almacena el nuevo registro y confirma que la operación se completó correctamente. |
| 10. El administrador consulta el resultado del registro. | 10. El sistema muestra un mensaje de éxito y los datos principales de la línea registrada. |
| 11. El administrador decide continuar administrando el sitio o cerrarlo. | 11. El sistema sigue su curso y el caso de uso finaliza. |

### Flujos alternativos

| ID Flujo | Situación | Acción Sistema |
|---|---|---|
| **FA01** | El administrador decide cancelar el registro. | El sistema solicita la confirmación de la cancelación y procede a abortar la operación. |
| **FA02** | Falta rellenar un campo requerido. | El sistema identifica los campos incompletos y muestra un mensaje pidiendo rellenarlos. |
| **FA03** | Un dato ingresado tiene un formato incorrecto. | El sistema señala el campo inválido e indica el formato esperado. |
| **FA04** | Se detecta una posible línea de ayuda duplicada. | El sistema informa que existe un registro similar y presenta la información duplicada sin concluir con el proceso. |
| **FA05** | El administrador desea registrar otra línea de ayuda. | El sistema ofrece registrar más líneas de ayuda. |
| **FA06** | Error de conexión con el sistema. | El sistema informa que no fue posible guardar la información y cancela el proceso. |
| **FA07** | Se produce un error durante el almacenamiento de información. | El sistema informa del fallo y aborta la operacón. |
| **FA08** | El administrador no tiene permisos para registrar líneas de ayuda. | El sistema deniega el acceso a la operación y muestra un mensaje de autorización insuficiente. |
| **FA09** | La sesión del administrador ha expirado. | El sistema solicita autentificar nuevamente al administrador. |

### Cierre

| Campo | Descripción |
|---|---|
| **Poscondición** | 1. Exito: La nueva línea de ayuda se encuentra almacenada en el sistema.
2. Cancelación o Error: El sistema no almacena la modificación del registro y/o informa del error. |
| **Frecuencia** | Siempre |
| **Importancia** | Permitir al administrador agregar nuevas líneas de ayuda en caso de existir. |
