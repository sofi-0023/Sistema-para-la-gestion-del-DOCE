## Requisito

RF06 - El sistema deberá permitir la gestión y visualización de las líneas de ayuda universitarias, así también las de disposición general locales, estatales y nacionales para los usuarios.

## Caso de uso

| Campo | Descripción |
|---|---|
| **Nombre del Caso de Uso** | Visualizar las líneas de ayuda |
| **Código del Caso de Uso** | CU-06_1 |
| **Actor(es)** | Usuario del Sistema |
| **Precondición(es)** | 1.- El sistema debe estar disponible.<br>2.- El usuario debe poder acceder al sistema.<br>3.- El módulo de líneas de ayuda está habilitado para consulta.<br>4.- Deben existir líneas de ayuda registradas en el sistema. |

### Objetivo

Permitir que los usuarios visualicen las líneas de ayuda disponibles en el sistema.

### Flujo principal

| Acción Actor | Acción Sistema |
|---|---|
| 1. El usuario accede al sistema. | 1. El sistema muestra la opción para consultar las líneas de ayuda. |
| 2. El usuario selecciona la opción "Líneas de ayuda".  | 2. El sistema recibe la solicitud de visualización del catálogo y redirecciona al usuario para verlas. |
| 2.1  | 2.1 El sistema consulta el registro de las líneas de ayuda disponibles. |
| 2.2  | 2.2 El sistema organiza los registros por ámbito de atención: universitario, local, estatal y nacional. |
| 2.3  | 2.3 El sistema presenta el catálogo de líneas de ayuda al usuario. |
| 3. El usuario revisa las líneas de ayuda mostradas. | 3. El sistema mantiene visible el catálogo mientras el usuario permanece en esta sección. |
| 4. El usuario decide continuar en el sitio. | 4. El sistema permanece sin cambios. |
| 5. El usuario decide cerrar y/o cambiar de sección. | 5. El sistema sigue su curso y el caso de uso finaliza. |

### Flujos alternativos

| ID Flujo | Situación | Acción Sistema |
|---|---|---|
| **FA01** | No existen líneas registradas. | El sistema muestra un mensaje indicando que no hay líneas de ayuda disponibles. |
| **FA02** | El usuario desea consultar un ámbito específico de la sección. | El sistema permite seleccionar el ámbito y muestra su respectivo contenido. |
| **FA03** | Ocurre un error al recuperar la información registrada. | El sistema muestra un mensaje de error e indica que no fue posible cargar las líneas. |
| **FA04** | Se pierde la conexión con el servidor. | El sistema muestra un mensaje de error con la conexión a internet e indica que no fue posible cargar el sitio. |

### Cierre

| Campo | Descripción |
|---|---|
| **Poscondición** | 1. Éxito: El usuario visualiza el catálogo de líneas de ayuda disponibles.<br>2. Sin Resultados: El usuario recibe un mensaje que informa que no hay líneas de ayuda registradas.<br>3. Error: El sistema informa al usuario que no pudo cargar las líneas de ayuda. |
| **Frecuencia** | Siempre |
| **Importancia** | Permite a los usuarios visualizar las líneas de ayuda disponibles en caso de requerirlas. |
