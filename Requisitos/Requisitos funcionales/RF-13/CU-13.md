## Caso de uso

| Campo | Descripción |
|---|---|
| **Nombre del Caso de Uso** | Consulta de contactos de apoyo y guías de carrera |
| **Código del Caso de Uso** | CU-13 |
| **Actor(es)** | Estudiante |
| **Precondición** | Estar autenticado en el sistema |

### Objetivo

Permitir al estudiante consultar los contactos de apoyo (tutorías) y las guías de carrera disponibles.

### Flujo principal

| Acción Actor | Acción Sistema |
|---|---|
| 1. Selecciona la opción de tutorías o guías de carrera. | 1. Muestra la lista de contactos de apoyo y guías disponibles. |
| 2. Selecciona un contacto o guía para ver detalles. | 2. Despliega la información detallada de contacto y orientación. |

### Flujos alternativos

| Flujo | Acción Actor | Acción Sistema |
|---|---|---|
| **Flujo Alternativo 1:** | No hay registros disponibles para mostrar. | 1. El sistema muestra la lista vacía.<br>2. Muestra el mensaje "No hay contactos o guías registradas en este momento". |
| **Flujo Alternativo 2:** | El servidor no se pudo conectar. | 1. El usuario se mantiene en la pantalla.<br>2. Muestra el mensaje "No se pudo conectar con los servidores, intenta de nuevo más tarde". |

### Cierre

| Campo | Descripción |
|---|---|
| **Poscondición** | El usuario consultó la información de tutorías o guías de carrera disponibles. |
| **Frecuencia** | Frecuente |
| **Importancia** | Indispensable para la orientación académica del estudiante. |
