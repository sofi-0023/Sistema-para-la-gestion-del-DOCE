## Requisito

RF10 - El sistema deberá permitir la gestión y visualización de las líneas de ayuda universitarias, así también las de disposición general locales, estatales y nacionales para los usuarios.

## Caso de uso

| Campo | Descripción |
|---|---|
| **Nombre del Caso de Uso** | Visualizar las líneas de ayuda |
| **Código del Caso de Uso** | CU-10_1 |
| **Actor(es)** | Usuario del Sistema |
| **Precondición(es)** | 1.- El sistema debe estar disponible.
2.- El usuario debe poder acceder al sistema.
3.- Deben existir líneas de ayuda registradas en el sistema. |

### Objetivo

Permitir que los usuarios visualicen las líneas de ayuda disponibles en el sistema.

### Flujo principal

| Acción Actor | Acción Sistema |
|---|---|
| 1. El usuario busca en el directorio por un área de especialidad con la que desee ser atendido.  | 1. El sistema despliga un menu de interacción en el que se clasifican todos los contactos registrados en el sitio. |
| 2. El usuario desea ver los contactos registrados de alguna especialidad de su interés. | 2. El sistema muestra al usuario un listado de contactos de la clasificación de su interés, junto con la dependencia a la que pertenece, horarios de atención y direcciones físicas en caso de tener. |
| 3. El usuario desea acceder a los servicios digitales de apoyo a la salud mental desde alguna dirección proporcionada desde la plataforma. | 3. El sistema redireccionará al usuario a la dirección de origen de aquel URL. |
