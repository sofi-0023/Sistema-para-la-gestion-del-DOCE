## Requisito

RF10 - El sistema deberá permitir la gestión y visualización de las líneas de ayuda universitarias, así también las de disposición general locales, estatales y nacionales para los usuarios.

## Caso de uso

| Campo | Descripción |
|---|---|
| **Nombre del Caso de Uso** | Modificar líneas de ayuda |
| **Código del Caso de Uso** | CU-10_3 |
| **Actor(es)** | Administrador del sistema |
| **Precondición** | 1.- El sistema debe estar disponible.
2.- El administrador debe poder acceder al sistema.
3.- El administrador ha validado sus credenciales como "administrador".
4.- El administrador cuenta con los permisos necesarios para modificar líneas de ayuda.
5.- Existe una línea de ayuda previamente registrada.
6.- El sistema dispone de la función de edición de líneas de ayuda.
7.- El administrador dispone de la información a actualizar. |

### Objetivo

Permitir que el administrador mantenga actualizada la información de las líneas de ayuda registradas en el sistema, asegurando que los cambios sean validados y almacenados correctamente para que el catálogo refleje los datos vigentes.

### Flujo principal

| Acción Actor | Acción Sistema |
|---|---|
| 1. El administrador ingresa al sistema. | 1. El sistema presenta la pantalla principal o el panel administrativo, con sus respectivos permisos. |
| 2. El administrador accede al módulo de gestión de líneas de ayuda. | 2. El sistema muestra las opciones disponibles para administrar los registros. |
| 3. El administrador selecciona la opción para modificar líneas de ayuda. | 3. El sistema recupera y muestra las líneas de ayuda registradas. |
| 4. El administrador localiza y selecciona la línea de ayuda que desea modificar. | 4. El sistema identifica el registro seleccionado. |
| 4.1 | 4.1 El sistema verifica que el administrador tenga permiso para realizar la operación. |
| 4.2 | 4.2 El sistema recupera los datos actuales de la línea de ayuda seleccionada. |
| 4.3 | 4.3 El sistema presenta el formulario de edición con la información existente. |
| 5. El administrador modifica uno o varios campos de información. | 5. El sistema recibe los nuevos valores introducidos. |
| 6. El administrador solicita guardar los cambios. | 6. El sistema recibe la solicitud de actualización. |
| 6.1 | 6.1 El sistema verifica que los campos requeridos estén completos. |
| 6.2 | 6.2 El sistema valida los formatos de los datos capturados. |
| 6.3 | 6.3 El sistema comprueba si existe un registro con el que se considere duplicado. |
| 6.4 | 6.4 El sistema almacena la nueva inforación y confirma que la operación se completó correctamente. |
| 7. El administrador consulta el resultado de la modificación. | 7. El sistema muestra la información actualizada y un mensaje de confirmación de cambio. |
| 8. El administrador decide continuar administrando el sitio o cerrarlo. | 8. El sistema sigue su curso y el caso de uso finaliza. |

### Flujos alternativos

| ID Flujo | Situación | Acción Sistema |
|---|---|---|
| **FA1** | El administrador no encuentra la línea de ayuda deseada. | El sistema informa que el registro ya no está disponible. |
| **FA2** | El administrador decide no cambiar determinados campos. | El sistema conserva los valores originales de esos campos y modifica los deseados. |
| **FA3** | El administrador cancela la modificación. | El sistema solicita la confirmación de la cancelación y procede a abortar la operación. |
| **FA4** | Falta un campo requerido. | El sistema identifica los campos incompletos y muestra un mensaje pidiendo rellenarlos. |
| **FA5** | Un dato ingresado tiene un formato incorrecto. | El sistema señala el campo inválido e indica el formato esperado. |
| **FA6** | Otro administrador modificó el registro después de que se abrió el formulario. | El sistema detecta que los datos almacenados han cambiado e informa al administrador de la modificación. |
| **FA7** | Los cambios provocan una posible duplicidad. | El sistema informa de la coincidencia, permite revisar los datos y permanece sin moficar la línea de ayuda. |
| **FA8** | El administrador desea modificar otra línea. | El sistema ofrece modificar más líneas de ayuda. |
| **FA9** | Error de conexión con el sistema. | El sistema informa que no fue posible modificar la información y cancela el proceso. |
| **FA10** | Se produce un error durante la modofocaión de la información. | El sistema informa del fallo y aborta la operacón. |
| **FA11** | El administrador no tiene permisos para modificar líneas de ayuda. | El sistema deniega el acceso a la operación y muestra un mensaje de autorización insuficiente. |
| **FA12** | La sesión del administrador ha expirado. | El sistema solicita autentificar nuevamente al administrador. |
| **FA13** | La línea de ayuda fue eliminado por otro administrador. | El sistema informa que la línea ya no existe y cancela todo el proceso. |

### Cierre

| Campo | Descripción |
|---|---|
| **Poscondición** | 1. Exito: El sistema confirma que la modificación se completó correctamente y se actualiza el sistema.
2. Cancelación o Error: El sistema no almacena la modificación del registro y/o informa del error. |
| **Frecuencia** | Siempre |
| **Importancia** | Poder actualizar la información a la actual de las líneas de ayuda. |
