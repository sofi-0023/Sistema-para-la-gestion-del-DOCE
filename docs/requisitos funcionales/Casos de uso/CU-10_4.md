## Requisito

RF10 - El sistema deberá permitir la gestión y visualización de las líneas de ayuda universitarias, así también las de disposición general locales, estatales y nacionales para los usuarios.

## Caso de uso

| Campo | Descripción |
|---|---|
| **Nombre del Caso de Uso** | Eliminar casos de uso |
| **Código del Caso de Uso** | CU-10_4 |
| **Actor(es)** | Administrador del sistema |
| **Precondición** | 1.- El sistema debe estar disponible.
2.- El administrador debe poder acceder al sistema.
3.- El administrador ha validado sus credenciales como "administrador".
4.- El administrador cuenta con los permisos necesarios para eliminar líneas de ayuda.
5.- Existe una línea de ayuda previamente registrada.
6.- El sistema dispone de la función para eliminar líneas de ayuda. |

### Objetivo

Permitir que un administrador retire una línea de ayuda del catálogo del sistema cuando ya no deba estar disponible para consulta.

### Flujo principal

| Acción Actor | Acción Sistema |
|---|---|
| 1. El administrador ingresa al sistema. | 1. El sistema presenta la pantalla principal o el panel administrativo, con sus respectivos permisos. |
| 2. El administrador accede al módulo de gestión de líneas de ayuda. | 2. El sistema muestra las opciones disponibles para administrar los registros. |
| 3. El administrador selecciona la opción para eliminar líneas de ayuda. | 3. El sistema recupera y muestra las líneas de ayuda registradas. |
| 4. El administrador localiza y selecciona la línea de ayuda que desea eliminar. | 4. El sistema identifica el registro seleccionado. |
| 4.1 | 4.1 El sistema verifica que el administrador tenga permiso para realizar la operación. |
| 4.2 | 4.2 El sistema muestra una pantalla de confirmación con información suficiente para identificar la línea de ayuda y advertir sobre las consecuencias de la operación. |
| 5. El administrador revisa la información y confirma que desea eliminar la línea de ayuda. | 5. El sistema elimina la línea de ayuda del mismo sistema. |
| 5.1 | 5.1 El sistema muestra un mensaje indicando que la línea de ayuda fue retirada con éxito. |
| 5.2 | 5.2 El sistema actualiza el estado del sitio. |
| 6. El administrador consulta el resultado de la modificación. | 7. El sistema muestra la información actualizada. |
| 7. El administrador decide continuar administrando el sitio o cerrarlo. | 8. El sistema sigue su curso y el caso de uso finaliza. |

### Flujos alternativos

| ID Flujo | Situación | Acción Sistema |
|---|---|---|
| **FA1** | El administrador cancela la operación. | El sistema cierra la confirmación y no modifica el registro. |
| **FA2** | La línea ya está retirada. | El sistema informa de su estado actual. |
| **FA3** | El administrador selecciona otra línea de ayuda. | El sistema presenta los datos de la nueva selección y solicita una confirmación de su eliminación. |
| **FA4** | La línea está marcada como esencial o prioritaria. | El sistema impide la eliminación de la línea de ayuda y muestra un mensaje de la razón. |
| **FA5** | Error de conexión con el sistema. | El sistema informa que no fue posible modificar la información y cancela el proceso. |
| **FA6** | El administrador no tiene permisos para eliminar las líneas de ayuda. | El sistema deniega el acceso a la operación y muestra un mensaje de autorización insuficiente. |
| **FA7** | La sesión del administrador ha expirado. | El sistema solicita autentificar nuevamente al administrador. |

### Cierre

| Campo | Descripción |
|---|---|
| **Poscondición** | 1. Exito: El sistema confirma que la modificación se completó correctamente y se actualiza el sistema.
2. Cancelación o Error: El sistema no modifica el sitio y/o informa del error. |
| **Frecuencia** | Siempre |
| **Importancia** | Elimianr los registros de líneas de ayuda que se encuentren fuera de servicio para cualquier usuario. |
