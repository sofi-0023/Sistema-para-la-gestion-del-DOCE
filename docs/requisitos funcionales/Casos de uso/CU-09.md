RF01 - El sistema mostrará una fotogalería con imágenes de las actividades de salud mental realizadas en la Facultad de Matemáticas, disponible para su consulta por estudiantes y visitantes.

## Caso de uso

<!-- Llena la tabla. Puedes agregar o quitar filas en el flujo principal y en los flujos alternativos. -->

| Campo | Descripción |
|---|---|
| **Nombre del Caso de Uso** | Fotogalería  |
| **Código del Caso de Uso** | CU-09 |
| **Actor(es)** | Usuarios de la plataforma (alumnos se la facultad de matemáticas UADY y el departamento de orientación y consejo educativo) |
 **Precondición** |
El usuario entrara en la sección de fotogalería  |

### Objetivo

El usuario puede acceder y visualizar todas las fotografias relacionas con a salud mental realizadas en la facultad de matematica UADY (Universidad Autonoma de Yucatán).

### Flujo principal

| Acción Actor | Acción Sistema |
|---|---|
| 1. El usuario selecciona la sección de la fotogalería. | 1. El sistema muestra las imágenes publicadas correspondientes a las actividades de salud mental realizadas en la Facultad de Matemáticas UADY en formato de cuadricula de figuras rectangulares o cuadradados. |
| 2. El usuario recorre la galería para consultar otras imágenes| 2. El sistema Permite visualizar las imágenes siguientes conforme el usuario se desplaza por la galería (Horizontal).  |

### Flujos alternativos

| Flujo | Acción Actor | Acción Sistema |
|---|---|---|
| **Flujo Alternativo 1:** | Accede a la sección de fotogalería. | 1) Muestra un mensaje indicando que no hay imágenes disponibles para consultar. |
| **Flujo Alternativo 2:** | Accede a la sección de fotogalería. | 1)Informa que no fue posible mostrar las imágenes. |

### Cierre

| Campo | Descripción |
|---|---|
| **Poscondición** | El usuario consulta las imágenes disponibles o recibe información cuando no es posible mostrarlas. |
| **Frecuencia** | Cada vez que un usuario acceda a la fotogalería. |
| **Importancia** | Una manera de demostrar que se cumplen las actividades relacionadas con la salud mental. |
